\subsection{Análisis del Módulo 2}

En esta sección se presenta un análisis,comparacción y selección
del lenguaje de programación considerado para llevar a cabo el 
desarrollo del analisis de datos.Tomando en cuenta los requeriminetos 
funcionales \ref{it:RF04} y el formato de datos (JSON) previamente seleccionado con 
el cual va a trabajar el módulo 1 , 
lo que es de suma importancia que el lenguaje de programación
seleccionado tenga una integración nativa para el manejo de este formato.
\newline
De la \cref{tab:lenguajesprogramacion}, donde se comparan diferentes lenguajes de programación, 
de los cuales se seleccionó Python, ya que este lenguaje orientado a objetos cuenta con la 
caracterisitca principal de permitir
la herencia de propiedades y
métodos en subclases, facilitando la reutilización de código sin duplicación lo que simplfica mucho el código
y el almacenamiento para implementarlo. Además, su polimorfismo
soporta procesos de análisis simultáneos sin afectar el rendimiento entre ellos, gracias a un amplio ecosistema 
con librerías para manejo nativo de JSON y librerias nativas de lógica difusa. 
Siendo que Python también ofrece prototipado rápido, integración sencilla 
con servicios, visualización avanzada y soporte para aprendizaje automático. Por ello, presenta la mejor 
relación entre facilidad de uso, herramientas y comunidad para el Módulo 2. En contraste, C\# se limita al 
ecosistema .NET, complicando su implementación, mientras que R, aunque  no se descarta su uso debido a 
se excelente rendimiento en secuencias de datos, se enfoca en análisis estadístico y academico
limitando su flexibilidad hacia el desarrollo web.

\section*{Abstract}

The objective of this project is to develop a technological tool that allows 
artisanal kefir producers to optimize kefir harvesting time and determine whether 
its fermentation was optimal, in order to ensure product quality. To this end, 
four modules will be developed. The first module will collect data from the fermentation 
process using sensors. This data will be processed in the second module, where an analysis 
will be performed using a fuzzy logic rule-based model to assess the state of the 
fermentation. The third module will then store both the data obtained from the sensors 
and the analysis results in a database. Finally, the fourth module will allow all this 
information to be viewed via a website. This system will provide artisanal kefir producers 
with the ability to analyze their fermentations based on structured data, rather than 
relying solely on empirical knowledge.

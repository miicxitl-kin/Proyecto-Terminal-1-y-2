## Resumen  
En este repositorio se presenta la documentación correspondiente al desarrollo del proyecto titulado:

**"Prototipo de un sistema telemático para el monitoreo de la fermentación artesanal del kéfir de leche"**


El objetivo principal es desarrollar una herramienta tecnológica que permita a los productores de kéfir artesanal optimizar el tiempo de recolección y evaluar si el proceso de fermentación se llevó a cabo de manera adecuada, con el fin de garantizar la calidad del producto.

El sistema está compuesto por cuatro módulos principales:

- **Módulo 1:** Sistema de sensores (MQTT)  
- **Módulo 2:** Análisis de datos (lógica difusa)  
- **Módulo 3:** Base de datos  
- **Módulo 4:** Página web  

Este enfoque permite a los productores analizar sus procesos de fermentación a partir de datos estructurados, reduciendo la dependencia exclusiva de conocimientos empíricos.
